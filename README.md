# Aurum & Co. — Luxury Jewellery Store

A responsive React storefront for an offline jewellery shop moving online. It includes a home page, category pages for bangles, necklaces, earrings, rings and payals, 60 local mock products, search, pagination and a working client-side shopping bag.

## Run locally

```bash
cd frontend
npm install
npm start
```

The app is intentionally frontend-only and uses local mock data. A production backend, payment provider, inventory and CMS can be connected later.
